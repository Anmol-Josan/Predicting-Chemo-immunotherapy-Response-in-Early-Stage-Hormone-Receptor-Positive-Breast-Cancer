## Quick Start

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the Notebook
Open `Final_Notebook.ipynb` in Jupyter or VS Code and run all cells:
```bash
jupyter notebook Final_Notebook.ipynb
```

The notebook will:
- Download data from GEO (GSE300475)
- Preprocess scRNA-seq + TCR data
- Engineer multi-modal features (144 dimensions)
- Train ML models (LR, DT, RF, XGBoost) with LOPO cross-validation
- Train PyTorch deep learning models (MLP, CNN, BiLSTM)
- Generate SHAP feature importance analysis
- Save `final_model.pth`

### 3. Run the Streamlit App
```bash
streamlit run app.py
```
Then open http://localhost:8501 in your browser.

**Input modes:**
- **Manual:** Enter TRA and TRB CDR3 amino acid sequences
- **CSV Upload:** Upload a CSV with `cdr3_TRA` and `cdr3_TRB` columns

**Output:** Responder / Non-Responder prediction with confidence score.

## Validation Strategy

**Leave-One-Patient-Out (LOPO)** cross-validation:
- Each fold holds out one patient's entire data
- Prevents data leakage between patients
- Inner GroupKFold loop for hyperparameter tuning
- Patient-level aggregation of cell-level predictions

## Feature Architecture (144 dimensions)

| Component | Dimensions | Source |
|-----------|-----------|--------|
| Gene Expression PCA | 15 | scRNA-seq HVGs |
| TRA k-mer SVD | 50 | CDR3α 3-mers |
| TRB k-mer SVD | 50 | CDR3β 3-mers |
| Physicochemical | 6 | CDR3 properties |
| Enhanced Physicochemical | 14 | Extended properties |
| QC Metrics | 3 | n_genes, total_counts, pct_mt |
| Diversity Metrics | 6 | Shannon entropy, clonality |
