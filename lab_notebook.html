Project Overview

Scientific Question: Can unsupervised machine learning applied to single-cell RNA-sequencing (scRNA-seq) data from hormone receptor–positive (HR+) breast cancer patients treated with nab‑paclitaxel and pembrolizumab identify immune cell clusters and transcriptomic biomarkers associated with treatment response?

Data: scRNA-seq data from HR+ breast cancer patients (GEO dataset; processed via Kaggle GPU environment with 2× T4 GPUs). Dataset includes GEO accession GSM9061665.

Primary Notebook: Code/hr-cancer.ipynb (main analysis); Kaggle cloud runs tracked as versioned Kaggle Notebook "HR+ Cancer".

Key Findings: Responders exhibit expansion of GZMB+ cytotoxic CD8 T cells, dynamic TCR clonality, and interferon-driven monocyte/B cell signatures; non-responders display exhausted, static immune states. Best clustering silhouette score achieved: 0.918.

Analysis Method Summary

Data

Single-cell RNA-seq data from HR+ breast cancer patients (nab-paclitaxel + pembrolizumab treatment study). GEO accession GSM9061665 (features file: GSM9061665_S1_features.tsv.gz). Processed with AnnData/Scanpy pipeline.

Clustering Methods Evaluated

K-Means, HDBSCAN, Agglomerative Clustering, Leiden, Louvain. Best configuration selected automatically by silhouette score. Final best silhouette score: 0.918.

Machine Learning Pipeline

Preprocessing: normalization, log-transform, highly variable gene selection, PCA. Dimensionality reduction: PCA → UMAP. Clustering → cluster labeling → marker gene identification (GZMB+, interferon signatures). Supervised classification: XGBoost (XGBClassifierSK), LASSO regression, transformer-based model (partially integrated). Pseudobulk differential expression analysis. TCR sequence clustering.

Execution Environment

Kaggle with 2× NVIDIA T4 GPUs. Total wall-time (~10 hours 47 min for full run). Local execution requires ≥30 GB RAM.

Key Biological Findings

Responders: Expanded GZMB+ cytotoxic CD8 T cells, dynamic TCR clonality, interferon-driven monocyte and B cell signatures.
Non-responders: Exhausted, static immune states.
